# Quick Leaf Decay

**Quick Leaf Decay** makes leaves decay rapidly (1-2 seconds) after you cut down a tree trunk, instead of lingering in the air for minutes. Natural leaf particles, item drops (apples, saplings, sticks), and smooth cascading waves!

---

## Features

- **Fast & Natural**: Leaves decay within 1-2 seconds in smooth, satisfying waves.
- **Full Drop Rates**: Apples, saplings, sticks, and modded leaf drops drop at full vanilla probabilities.
- **Player Leaves Protected**: Player-placed leaves (`PERSISTENT`) will NEVER decay.
- **Zero Lag**: Uses Minecraft's native lightweight block tick scheduler (`scheduleTick`) instead of heavy chunk scanners.
- **Singleplayer & Server-Side**: Works on dedicated servers (vanilla clients can join without installing any mod) and in singleplayer worlds.
- **Zero Config**: Install and forget.
